DASHBOARD

Double-click Start-Dashboard.cmd to start the current version.
Or run .\Start-Dashboard.ps1 from this folder.
Keep the terminal open. Ctrl+C closes the dashboard server.
The root Dashboard.exe is the older packaged build.

THE SCREEN
    Projects sidebar: select a project, add one, or rescan its definitions.
    Project pane: run actions, watch output, and use Finish or Stop.
    Dashboard settings: install or reinstall the shared browser engine.
    Stop all projects: stops project actions across the workspace.

Finish presses Enter for a program waiting for you. Stop force-closes that
program and its browser. Several projects can run at once.

THE FOLDERS
    dashboard\      dashboard source and UI
    projects\       project definitions, sources, and local programs
    runtime\        dashboard builds and generated output (ignored by Git)
    runtime\logs\<project-id>\last-run.log
                    the dashboard's most recent log for each project

Shared project browser files remain in projects\managed\, projects\runs\,
and projects\artifacts\. Saved ChatGPT sign-in stays in the browser profile.
These folders, project-generated logs, and test reports are ignored by Git.

Dashboard and projects stay in the same repository for now. For an external
project workspace later, use Start-Dashboard.ps1 -Projects <full folder path>.

ADDING PROJECTS
Use "+ Add project" to point at a folder and executable you already have,
or add a project.json folder under projects\ and click Rescan.

The running dashboard never commits, pushes, resets, or checks out Git files.
